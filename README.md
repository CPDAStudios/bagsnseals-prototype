# Bags n’ Seals Website Prototype

Premium responsive homepage prototype for Bags n’ Seals by Hermetic LLC.

## Structure

- `index.html` — semantic homepage markup
- `styles.css` — responsive visual system
- `script.js` — navigation and progressive reveal interactions
- `assets/images` — approved project photography and brand assets

## Preview

The staging deployment is intended for:

`https://cpdastudios.com/bagsnseals_prototype/`

The current Squarespace commerce site remains unchanged. Product and contact calls-to-action link to its native commerce pages.
